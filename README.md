# Сервіс підписки на оновлення погоди

Цей сервіс реалізовано як частину технічного завдання під час проходження відбору до навчання. Завданням є надання актуальної інформації про погоду у вибраних містах, а також можливість підписки на оновлення на щогодинній або щоденній основі.

## Основна логіка сервісу

- Сервіс дозволяє:
  - Отримувати актуальну інформацію про погоду для заздалегідь визначених міст.
  - Відправити запит на підписку на оновлення погоди за електронною поштою — щогодини або щодня.
  - Підтвердити або скасувати підписку використовуючи посилання з унікальним токеном що надходить у електронному листі.
  - Отримувати листи з оновленнями погоди.
- Дані про міста, підписки, шаблони листів та налаштування зберігаються у базі даних PostgreSQL.
- Після запуску сервіс автоматично завантажує тестові (mock) дані для демонстрації функціоналу.

## Використані технології та бібліотеки

- **GORM** — використовується як ORM для роботи з базою даних.
- **Flyway** — використовується для запуску дата-міграцій при старті сервісу. Flyway працює у вигляді окремого контейнера в `docker-compose`, запускається після БД, але до запуску основного застосунку.
- **PostgreSQL** — основна база даних сервісу.
- **Google SMTP** — використовується як поштовий провайдер, але налаштування сервісу дозволяють використовувати будь-який інший SMTP-сервер.
- **HTML-інтерфейс** — реалізована базова HTML-сторінка для швидкої підписки на оновлення або отримання актуальної інформації про погоду у вибраному місті.

## Тестування

- Допоміжні утиліти сервісу покрито юніт-тестами у якості референсу. У цільовій реалізації інші функції також мають бути покриті тестами

## Архітектурні патерни
- Логіку сервісу було розділено на 3 шари:
  - Транспортний рівень - handlers що викликаються при зверненні до кінцевих точок та займаються виключно обробкою http запитів і конвертацією даних
  - Рівень бізнес-логіки - функції які використовуються для забезпечення виконання цілі користувача
  - Інфраструктурний рівень - функції які взаємодіють з базою даних, сервісами розсилок, або файлами налаштувань
